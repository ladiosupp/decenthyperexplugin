# HyperEx 2.2.0 handoff — 2026-10-31

2.2.0 把控制从“绝对指令 + 单杯学习”推进到“杯间增益记忆 + 杯内预测 + S3 drift 形状”。本版改动较大，建议先按第 4 节真机顺序跑。

## 1. 当前状态

- 版本号：manifest / PLUGIN_VERSION = 2.2.0。
- 测试：tests/verify_v0220.cjs 614/614（RESULTS_v0220.txt）。
- 旧 live-trim 分支保留在 `liveTrimDecisionModel=false`；旧三段 S3 形状仍按 legacy 读取。
- 没有改 arming / 校准触发时机，没有改 LUT 生成逻辑。

## 2. 改动

### 杯间增益记忆

- `adaptiveHistoryFileV2.gainMemory` schema 1。
- S2 后段 40% 的 `压力 / 机器流量` 中位数做签名，带 1.25× 滞回；签名落在桶外时新建桶，不按纸名分支。
- 每桶存 S2/S3 的 `r = 稳态杯流 / 当杯实际指令`；下一杯基值 = `target / r`，限制在 `[0.1, min(8, LUT×2)]`。
- 偏差 >15% 时降置信、下一杯用当杯局部 r，桶以 0.55 吸收；常规 0.35。常规杯内介入回填 0.12，救急回填 0.5。
- 质量门放宽为覆盖 60%、限压占比 <35%、机器流量欠跟踪 <40%；压力极限/ACK/预算仍是硬门。

### 杯内预测

- 常规写入后 1.2 s 静默，救急 0.8 s。
- S2 1.6 s 回归 + 2 s 前瞻；S3 3 s 鲁棒回归 + 1.2 s 前瞻。
- 4% 预测死区；救急三条：趋势角 ≥120° 连续两次、预测回不到带内、误差 >25%。
- 常规 ±1/±2/±4 档，救急 8–24 档；S3 常规最多 4 笔、救急最多 2 笔，后 55% 只允许救急/角度确认。
- 压力限制只阻断向上加码，向下卸压仍允许。

### S3 形状与补水

- S3 新增 `model:"drift"`：MID 为基准，`earlyFactor = early/MID`、`drift = late/MID`，允许 early > MID、late < MID。
- drift model 的 EARLY 只取帧后半段，避开 S2→S3 过渡；旧三段形状保持兼容。
- S3 折叠区新增手动倾斜开关 + 滑块：默认只读；开启并应用后锁 S3，自动学习只更新 S1/S2。
- S2 补水 `predictionSeconds` = 2.0，收口看 2 s 预测秤流量。

## 4. 真机建议顺序

1. 先装 2.2.0，保持默认 LIVE TRIM 开启，先确认首杯 controller 能起、HyperEx 能介入、结束后计时/状态正常退出。
2. 先跑一张熟悉的纸，观察 S2 是否不再出现 0.5 s 连发；看 “normal/rescue” 与 “silence holds” 计数。
3. 开启 S3 手动倾斜开关，先用 0 或很小的 tilt 验证只读/可调/应用/回读；确认手动锁后自动学习只改 S2，不改 S3。
4. 再跑换纸/大偏差杯，观察救急是否触发、是否被压力门挡住、有没有过冲（看秤流量，不看泵流量）。
5. 有异常先看诊断页的 next-shot 决策、S3 manual lock、S2 补水 predicted cutoff；不要把合成仿真的结论当绝对值。

## 5. 风险与回滚

- 0.8 s 救急间隔、8–24 档、S3 4+2 预算、95% 补水阻尼都还没有真机定稿。
- 如果 S3 drift 让曲线更差，先关闭手动倾斜并让自动学习重新接管，或回滚到 v2.1.3。
- 如果 S2 补水在预测收口下提前/滞后明显，先回滚 v2.1.3；不要同时改多个控制参数。
- 回滚 tag：v2.1.3；本版 tag：v2.2.0。
